## 🚀 Featured Projects

### 🤖 AI-MailCraft

**AI-Powered Intelligent Email Generation & Management Platform**

An AI-powered email assistant that generates contextual email replies through both a web application and Gmail Chrome extension. Integrates Gemini API, multiple response tones, email management, and reusable templates.

**Tech:** Java • Spring Boot • React • Gemini API • Chrome Extension

---

### 🧠 Lexis AI

**AI-Powered Smart Notes & RAG Study Platform**

A Retrieval-Augmented Generation platform that allows users to upload study documents and interact with their content through an AI-powered interface. Designed to help students retrieve relevant information and receive document-grounded answers.

**Tech:** Python • FastAPI • Streamlit • RAG • Vector Database • Generative AI

---

### 🔐 VaultPad

**AI-Powered Automated Code & File Storage Platform**

An intelligent code and file storage platform where users can create secure vault workspaces through natural-language commands. Gemini-powered automation generates vaults and secret access codes, while an integrated AI assistant provides coding assistance and answers technical queries.

**Tech:** Node.js • Express.js • MongoDB • Cloudinary • Gemini API • AI Automation

---

### 🏠 Wanderlust

**Full-Stack Vacation Rental Booking Platform**

A vacation rental platform that allows users to explore, create, manage, and review properties. Implements authentication, role-based authorization, image uploads, interactive maps, and MVC architecture.

**Tech:** Node.js • Express.js • MongoDB • EJS • JavaScript • Cloud Services

---

### 📋 FlowBoard

**Smart Task Management System**

A full-stack task management application that helps users create, organize, prioritize, and track tasks through an intuitive dashboard with status-based workflows.

**Tech:** Node.js • Express.js • MongoDB • Mongoose • JavaScript • Bootstrap
